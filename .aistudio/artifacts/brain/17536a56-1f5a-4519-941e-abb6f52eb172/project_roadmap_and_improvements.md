# 🌟 Opinion Net — Паспорт проекта и план развития

> **Статус**: Активная разработка  
> **Стек**: Next.js (App Router) · React 18 · TypeScript · Tailwind CSS · Supabase (PostgreSQL, Auth, Realtime, Storage) · Redux Toolkit

---

## 1. Базовые основы и концепция проекта

### 1.1. Главная идея
**Opinion Net** — это мобильно-ориентированная платформа нового поколения для проведения честных фото-баттлов, тематических конкурсов и визуальных дуэлей. 
Пользователи голосуют за творческие работы в формате динамичной TikTok/Reels-ленты с естественными свайпами, а авторы получают признание, экспертную обратную связь и возможность выигрывать призовые фонды от брендов.

### 1.2. Фундаментальные принципы платформы
| Принцип | Как реализовано |
| :--- | :--- |
| **Честность и защита от накруток** | Система репутации **Trust Score**, схлопывание подозрительных IP, привязка веса голоса к стажу и активности аккаунта. |
| **Приватность выбора** | Кто за кого проголосовал — строго анонимно. Публично отображаются только итоговые проценты, без сырых чисел голосов. |
| **Иммерсивный фото-опыт** | Полноэкранный мобильный формат, плавные вертикальные свайпы 1v1, фоновое динамическое свечение (Ambient Glow) в тон кадра. |
| **Низкий порог входа** | Подача заявки в пару кликов (фото + описание + ссылка на портфолио/соцсети). |
| **Наглядная интерактивность** | Мгновенный отклик при выборе (уменьшение выбранной карточки на 12%, изумрудная неоновая подсветка, бейдж «Selected»). |

## 2. Ключевые форматы соревнований

1. **1v1 Battle Arena (Дуэли)**:
   - Вертикальный 50/50 сплит-экран двух соперников.
   - Свайпы вверх/вниз для бесконечного исследования новых пар.
   - Мгновенное голосование нажатием на понравившуюся половину.
2. **Турнирные группы (Stage Tournament)**:
   - Сетка участников (2x2 или списки) с раундами на выбывание.
   - Финалы лучших работ с распределением призовых мест.
3. **Live Race (Гонка в реальном времени)**:
   - Динамический онлайн-лидерборд на вебсокетах (Supabase Realtime).
   - Проценты и позиции участников меняются прямо на глазах у зрителей.
4. **Eternal Hall of Fame (Зал Славы)**:
   - Постоянно действующие голосования за лучшие работы всех времен с возможностью изменения своего голоса.

## 3. Что уже реализовано на текущем этапе

- [x] **TikTok-лента 1v1 дуэлей (`TikTokBattleView`)**:
  - Сенсорные свайпы (Touch Swipe) и перетаскивание (Drag & Drop) на мобильных.
  - Навигация стрелками клавиатуры (`↑` / `↓`).
  - Умный прелоадинг следующих пар фотографий в кэш браузера для мгновенного листания без задержек.
- [x] **Интерактивный отклик выбора**:
  - При голосовании выбранная фотография и весь компонент плавно сжимаются на **12%** (`scale-[0.88]`), подсвечиваются неоновым изумрудным кольцом и бейджем «Selected».
- [x] **Презентабельный экран деталей и фото-галереи (`PhotoLightbox`)**:
  - **Чистая авто-обрезка по умолчанию (`object-cover`)**: на экране деталей все работы отображаются в едином аккуратном формате без лишних переключателей, геометрических скачков и пустых полей.
  - **Интуитивный просмотр оригинала в полном размере**: клик по фотографии или кнопке «Оригинал / Увеличить» открывает полноэкранный просмотрщик с сохранением 100% оригинальных пропорций (`object-contain`) и удобным зумом (1x, 1.5x, 2.5x).
  - **Мульти-фото галерея**: поддержка нескольких снимков у одной заявки, карусель, свайпы, стрелки и полоса миниатюр.
  - **Динамический Ambient Glow**: цветное атмосферное свечение вокруг фото, генерируемое из палитры изображения.
- [x] **Карточки авторов и спонсоров**:
  - Верифицированные профили создателей, аватары, прямые ссылки на Instagram, Telegram, X (Twitter) и портфолио.
  - Брендированные плашки спонсоров турнира и призовые пулы.

## 4. План развития и улучшений (Roadmap & Feature Wishlist)

Ниже собраны ключевые улучшения, которые выведут продукт на уровень топовых мировых визуальных сервисов (Instagram, TikTok, VSCO, Behance).

### 🚀 Этап 1: Доработка мобильного фото-экспириенса
- [ ] **Двойной тап для голосования (Double-Tap to Vote)**:
  - Быстрый двойной клик/тап по фото карточки сразу отдает голос с красивой всплывающей анимацией (сердечко, вспышка молнии или неоновый огонь) в точке касания.
- [ ] **Тактильная отдача (Haptic Feedback)**:
  - Использование `navigator.vibrate([15])` при перелистывании баттла и `navigator.vibrate([30, 50, 30])` при подтверждении голоса на смартфонах.
- [ ] **Pinch-to-Zoom прямо в ленте**:
  - Возможность двумя пальцами приблизить фото в карточке баттла без обязательного открытия отдельного модального окна.
- [ ] **Сравнение «До / После» (Split Slider)**:
  - Для конкурсов ретуши, дизайна, архитектуры и макияжа — интерактивный ползунок разделения кадра.

### 🎨 Этап 2: Вовлечение и социальные механики
- [ ] **Комментарии и рецензии**:
  - Вкладка обсуждения работы в деталях с подсветкой мнений пользователей с высоким Trust Score.
- [ ] **Серии голосований (Daily Streaks)**:
  - Начисление бонуса к весу голоса за ежедневную активность (например, «7 дней подряд — +15% к весу голоса»).
- [ ] **Шеринг дуэли в Stories и Telegram**:
  - Автоматическая генерация красивой картинки для Stories с двумя соперниками, бейджем «VS» и QR-кодом для перехода к голосованию.
- [ ] **Вызов на дуэль (Challenger Mode)**:
  - Автор может кинуть персональный вызов другому автору на баттл в заданной тематике (Street, Portrait, Cyberpunk).

### 🛡️ Этап 3: Антифрод и алгоритмы Trust Score
- [ ] **Поведенческий анализ кликов**:
  - Отслеживание аномально быстрых автоматических кликов (боты/скрипты накрутки).
- [ ] **Детекция смены устройств**:
  - Анализ Fingerprint браузера и распределение веса при массовых голосованиях из одной подсети.
- [ ] **Статус верифицированного эксперта**:
  - Проверенные профессиональные фотографы и дизайнеры получают статус жюри с повышенным весом голоса.

### 💰 Этап 4: Монетизация и бренд-платформа
- [ ] **Спонсорские битвы под ключ**:
  - Личный кабинет брендов (Sony, Nike, Canon, Apple) для запуска собственных конкурсов с модерацией заявок и кастомным брендингом.
- [ ] **Чаевые авторам (Tips / Creator Grants)**:
  - Возможность зрителям поддержать автора понравившейся фотографии напрямую.
- [ ] **Витрина экипировки и пресетов**:
  - В профиле работы автор может указать камеру, объектив, софт или продавать свой Lightroom-пресет.

### ⚡ Этап 5: Архитектура и быстродействие
- [ ] **PWA (Progressive Web App)**:
  - Возможность установки на домашний экран смартфона как нативное приложение с оффлайн-кэшем.
- [ ] **WebP / AVIF конвертация на лету**:
  - Автоматическая оптимизация загружаемых пользователями тяжелых фотографий до 200–300 КБ без потери визуального качества.
- [ ] **Push-уведомления**:
  - Оповещения автора о начале голосования, прохождении в следующий этап или победе в дуэли.
