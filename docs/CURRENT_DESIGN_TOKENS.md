# Opinion Net — Текущая дизайн-система и цветовая схема

Этот файл содержит все актуальные дизайн-токены приложения: цветовую палитру (HEX и RGB), типографику, шрифты, размеры текста, радиусы скруглений и базовые параметры компонентов. Подготовлен для дизайн-бота и редизайна.

## 2. Типографика и шрифты (Typography)

### Семейства шрифтов (Font Families)
1. **Display (Заголовки и логотипы)**: `Unbounded`
   - Начертания (weights): `500` (Medium), `700` (Bold), `800` (ExtraBold), `900` (Black)
   - Fallback: `ui-sans-serif, system-ui, sans-serif`
2. **Body & UI (Основной текст интерфейса)**: `Manrope`
   - Начертания (weights): `400` (Regular), `500` (Medium), `600` (SemiBold), `700` (Bold), `800` (ExtraBold)
   - Fallback: `ui-sans-serif, system-ui, sans-serif`
3. **Secondary UI**: `Onest`

### Шкала размеров шрифтов (Type Scale)
| Уровень | Размер (rem / px) | Line Height | Где используется |
|---|---|---|---|
| `caption` | `0.6875rem` (11px) | `1.0rem` (16px) | Теги, бейджи, подписи авторов, подсказки |
| `tab` / `btn` | `0.8125rem` (13px) | `1.25rem` (20px) | Вкладки навигации, текст в кнопках |
| `body` | `0.875rem` (14px) | `1.4rem` (~20px) | Базовый текст, описания конкурсов |
| `title` | `1.0625rem` (17px) | `1.2rem` (~21px) | Названия карточек, имена участников в баттлах |
| `heading` | `1.25rem` (20px) | `1.15rem` (23px) | Заголовки страниц, названия баттлов |
| `hero` | `1.75rem` (28px) | `1.1rem` (31px) | Крупные проценты голосов (24% / 76%), счётчики |

## 4. Сетка и размеры (Layout Grid)

- **Мобильный контейнер (Mobile-first column)**:
  - `max-w-app`: `28rem` (448px) — центрированный компактный столбец для телефонов.
  - Боковые отступы экрана: `px-3` (12px) или `px-4` (16px).
  - Сетка дуэлей (1v1): `grid grid-cols-2 gap-3` (пропорция фото 3:4 или 4:5).
- **Десктоп (Desktop layout >= 1024px)**:
  - Боковая колонка навигации (SideNav): фиксированная ширина `240px` слева.
  - Основная рабочая область: `calc(100% - 240px)`.

## 5. Интерактивные состояния (States)

- **Выбранная карточка / участник**:
  - Рамка: `border-emerald-500` (`#10b981`)
  - Обводка (ring): `ring-2 ring-emerald-500/50`
  - Тень свечения: `shadow-[0_0_24px_rgba(16,185,129,0.35)]`
  - Галочка: круглая плашка `#10b981` с чёрной галочкой.
- **Невыбранная карточка / оппонент**:
  - `border-neutral-800` (`#262626`), прозрачность `opacity-55` или `opacity-60`.
- **Шкала баттла (Progress Bar)**:
  - Высота: `16px` – `20px` (`h-4 sm:h-5`), фон подложки `#18181c`.
  - Зелёная часть (выбор): `#10b981` с мягким свечением.
  - Серая часть (оппонент): `#52525b`.
- **Фокус клавиатуры**: `outline: 2px solid #ff6a2b; outline-offset: 2px;`
- **Выделение текста**: `background: rgba(201, 67, 11, 0.5); color: #ffffff;`
